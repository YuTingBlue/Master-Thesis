### Balancing Security, Cost, and Emissions: Modelling Taiwan’s Electricity Transition

This repository contains all R scripts and input datasets used for this thesis.

- "Energy_Security_Scoring.xlsx": Detailed breakdown of the scoring including references
- "Johnson_SB_pdfs.R": R-script that constructs the disruption probability distributions
- "Model Framework": R-script that implements the model framework numerically
- "model_data": Input data for the model framework
